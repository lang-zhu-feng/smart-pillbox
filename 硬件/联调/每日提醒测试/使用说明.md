## 打开程序

打开 [DailyReminderTest.ino](DailyReminderTest/DailyReminderTest.ino)。开发板选 ESP32 Dev Module，使用 ESP32 的实际串口（此前 COM7）。串口为 **115200**，发送命令时选择“新行”。
沿用现有接线：门磁 D33/GND；低电平蜂鸣器 VCC=3V3、I/O=D25、GND=GND；OLED SDA=D21、SCL=D22、VCC=3V3、GND=GND，SSD1306 128×64、地址 0x3C。改变接线前先断 USB。

## 每日规则

- 每日北京时间 **08:00**：短响三声。
- **08:00≤有效关→开动作＜09:00**：记录窗口内开盒，取消当天 09:00 超时响铃。保持打开不算新的开盒动作。
- 到 **09:00** 仍无窗口内有效开盒：连续响 **10 秒**后停止，不是无限响铃。
- **09:00 及以后**开盒可立即停铃，但记为迟到，不改写为窗口内按时开盒。开盒本身不证明已经服药。

## 串口命令与校时

| 命令 | 用途 |
| --- | --- |
| `time YYYY-MM-DD HH:MM:SS` | 有效命令退出演练后修改真实系统时钟；填入发送当刻的真实北京时间，收到 `TIME_OK UTC+8` 才算成功 |
| `?` | 查看 REAL/DEMO、时钟、门磁、NVS 和当前阶段 |
| `c` | 保持磁铁贴近，保存当前关盖极性；收到 `CLOSED_LEVEL_SAVED` 才算保存成功 |
| `b` | 手动三声自测 |
| `s` | 只停止当前声音，不取消未来 09:00 超时提醒 |
| `demo` | 开始独立缩时演练 |
| `real` | 提前退出演练、恢复真实计划 |

时区固定为 `CST-8`（UTC+8）。没有已校准的时钟时，真实计划禁止自动响铃；断电或重启后须重新发送 `time`。不要照抄历史示例日期或把真实系统钟快进来测试。
每次重启后可使用[同步北京时间.ps1](同步北京时间.ps1)，默认端口 COM7（可用 `-Port` 指定）。日后运行前先关闭 Arduino 串口监视器并确保电脑时钟准确；脚本按电脑当前 UTC+8 时间发送 `time`、检查 `TIME_OK`，结束后释放串口。本次未打开串口运行该脚本，未完成实机校时。
关盖极性默认沿用此前实测的“磁铁贴近=0”；`c` 的结果写入 NVS，和之前 `AllHardwareTest` 仅在 RAM 中校准的行为不同。

## 重启、回拨与当日记录

- 真实计划按真实日期在 NVS 保存当天一次性标记，重启或回拨时间不重复响已触发的提醒。
- 重启后仍须校时；若已有当天待完成记录，则恢复进度并按当前阶段追补，不套用“无当天记录则跳过”的规则。
- NVS 记录是本地调度状态，不是服务器服药记录；时钟与记录都不能替代真实开盒事件上传。

## 不等待明早的缩时演练

演练使用完全独立的虚拟日期、时钟与状态；`demo` 本身不改真实系统时钟，也不改 NVS 的 `daily` 真实日计划记录。显式执行 `c` 仍可保存 `closed` 关盖校准键，该键不属于 `daily` 日计划记录。有效 `time` 命令则会退出演练、修改真实时钟并按真实计划初始化，不作为虚拟快进使用。

1. 让磁铁贴近门磁，模拟关盖；发送 `demo`。
2. **超时路径**：保持不动。开始后约 **5 秒**模拟 08:00，响三声；约 **20 秒**模拟 09:00，连续响 10 秒后停。
3. **按时开盒路径**：另起一次 `demo`；在第 5 秒提醒后、第 20 秒超时点前，移开磁铁产生关→开动作，09:00 超时铃应取消。
4. 演练约 **32 秒**自动结束、恢复真实计划；`real` 可提前结束。演练中第 20 秒及以后开盒能停铃，但仍属迟到。
5. 发送 `?` 核对已回到 `REAL`，真实日期、时钟和当日标记未被演练覆盖。
