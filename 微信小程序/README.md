# 安心药伴：家属端微信小程序 Demo

这是“独居老人智能用药与居家安全管理系统”的家属端可点击原型。

## 当前包含的页面

1. 首页：老人状态、今日用药、异常摘要和快捷入口
2. 本周药盒：7 天 × 早中晚，共 21 个逻辑药格
3. 用药计划：查看、暂停和新增演示计划
4. 异常提醒：查看提醒、全部已读和模拟漏服异常
5. 老人档案：老人信息、设备状态和重置数据
6. 历史记录：查看开盒事件和逾期记录

## 演示交互

- 在首页点击“模拟开盒”，今日任务会变为“已完成”。
- 点击药盒中的待服药药格，可查看详情并模拟开盒。
- 点击“模拟一次超时未开盒”，系统会生成异常提醒。
- 用药计划可暂停或重新启用。
- 所有 Demo 数据保存在微信开发者工具的本地缓存中。
- “我的”页面可以重置全部演示数据。

## 导入微信开发者工具

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件所在的 `微信小程序` 文件夹。
4. 当前 `project.config.json` 使用 `touristappid`，用于无正式 AppID 的原型调试。
5. 导入后点击“编译”即可查看。

当前版本只使用模拟数据，不连接 FastAPI、MySQL 或真实 ESP32。
