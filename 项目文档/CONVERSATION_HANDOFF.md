# 服药管理系统项目交接文档

> 用途：新对话开始时阅读本文档，快速恢复项目背景、当前进度和协作方式。
> 本文档记录的是截至 2026-09-14 的实际情况。

## 一、项目背景

这是一个课程项目，计划周期约 16 周：

- 开始日期：2026-09-04
- 预计结束/答辩：2026-12-25 前后
- 指导老师：有企业工作经验的老师参与指导
- 团队名义人数：7 人，来自互金、软工、国贸、机械、工造、英语、建筑、视传等不同专业
- 预计持续深度参与：用户本人，可能再加 1 人

项目主题是智慧城市与可持续发展，但最终确定为：

> 面向独居老人的智能用药与居家安全管理系统。

项目服务对象主要是：

- 患有慢性病、需要长期服药的老人
- 独居或空巢老人
- 行动不便的老人

项目主要场景是家庭住宅。暂时可以使用青岛作为案例城市，但不强求必须依赖青岛数据。

## 二、核心问题和解决方案

主要解决：

- 老人忘记服药
- 老人吃错药或错过服药时间
- 子女无法及时知道老人是否完成当天用药

系统闭环：

```text
家属设置用药计划
        ↓
药盒在服药时间段提醒老人
        ↓
老人打开对应药格
        ↓
ESP32/模拟设备上传开盒事件
        ↓
Python 后端判断服药任务状态
        ↓
小程序更新状态
        ↓
超时未开盒时生成异常并通知家属
```

重要技术边界：

> 打开药格只能证明检测到开盒事件，不能证明老人已经把药吃进去了。
> 项目中应使用“服药完成状态”“开盒事件”“漏服风险提醒”等表述，
> 不宣称可以进行医学诊断或百分之百确认服药。

## 三、已经确定的功能

### 核心 MVP

1. 家属账号
2. 一个家属账号只绑定一位老人
3. 老人档案
4. 药物信息
5. 每周用药计划
6. 7 列 × 3 行药格状态展示
7. 一个药格允许放多种药
8. 药盒开盒事件接收
9. 服药时间区间判断
10. 语音或蜂鸣提醒
11. 漏服/逾期异常提醒
12. 家属端微信小程序查看状态
13. 历史用药记录
14. 家属端显示异常通知

### 药盒规则

- 7 列代表周一到周日
- 3 行代表早、中、晚
- 每个格子对应一次服药任务
- 不需要服药的格子显示“无需服药”
- 老人打开对应药格后，系统暂时将任务判断为“已完成”
- 药盒实际硬件先实现 1 个真实药格，条件允许时扩展到 3 个
- 软件界面展示完整的 21 个逻辑药格

### 默认提醒规则

- 进入服药时间段：提醒一次
- 之后每 10 分钟提醒一次
- 最多提醒 3 次
- 服药时间段结束后进入“已逾期”
- 再过 15 分钟仍未开盒：生成家属异常通知

### 第二优先级功能

- 每日“我平安”确认
- 设备在线/离线状态
- 微信订阅消息
- 简单用药风险统计

### 暂不做

- 医疗诊断
- 自动给药
- 药物相互作用判断
- 跌倒检测硬件
- 远程问诊
- 同时开发多个老人和多个家属关系
- 复杂机器学习模型

## 四、计划技术栈

### 后端

- Python
- FastAPI
- Uvicorn
- MySQL 8.0
- REST API
- 后期使用定时任务处理提醒和逾期判断

### 家属端

- 原生微信小程序
- JavaScript
- WXML
- WXSS

老人不要求使用微信小程序，主要通过药盒接收语音或蜂鸣提醒。

### 硬件

- ESP32
- Arduino C/C++
- Wi-Fi
- 微动开关或磁簧开关
- 蜂鸣器，条件允许时增加语音播放模块
- HTTP 或 MQTT 通信，初版优先选择更容易理解和调试的 HTTP

### 部署候选

- 腾讯云 CloudBase
- Python 后端云托管
- MySQL
- 小程序体验版或正式版
- 同时准备公网 H5 备用演示入口

微信小程序最终能否让所有人扫码使用，要看账号主体、开发版/体验版、
服务器 HTTPS、合法域名和平台审核状态。开发阶段可以先用开发者工具和
体验版；不能把本地地址 `127.0.0.1` 当作公网地址。

## 八、用户的学习要求

用户不希望只得到一个已经做好的成品。必须采用“教学 + 结对开发”的方式：

- 解释每一步解决什么问题
- 解释为什么选择这个工具
- 解释命令每一部分的含义
- 解释文件和目录是怎么来的
- 让用户亲自输入和修改关键代码
- 用户先尝试，再协助排错
- 不要一次性生成完整系统让用户复制
- 重要模块完成后，让用户用自己的话复述
- 每一步都告诉用户如何重新打开、运行和关闭
- 出错时先看报错、判断层次，再做最小测试

用户目前特别关心：

1. PyCharm 中为什么有很多文件
2. `.venv` 和 `site-packages` 是什么
3. 文件夹为什么这样命名
4. 如何修改页面上的文字
5. 如何重新打开 Swagger 页面
6. 如何在 PyCharm 中关闭服务或关闭项目
7. 以后遇到类似问题能自己判断，而不是只会照着做

回答风格要耐心、分步骤、少一次给太多内容。每次只布置一个
明确的小任务，并说明完成标准。
