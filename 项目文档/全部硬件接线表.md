# 全部硬件接线表

2026-11-08：用户确认 ESP32、OLED 屏幕、三针低电平触发蜂鸣器、两线磁簧开关及分线接头已到货。已完成下述接头通断检查，用户报告磁铁靠近、移开门磁时串口“已导通／未导通”能够切换。随后 `AllHardwareTest` 已成功上传 COM7，发送 `b`、`s` 获得串口回应，用户明确反馈“响了三声”，蜂鸣器三声实测通过。用户保持磁铁贴近后发送 `c` 成功，本次关盖电平校准为 0；校准仅在本次运行内有效，重启须重做。用户随后确认移开磁铁并保持约 5 秒时自动响三声后停止，观察期间保持打开不反复响；响声开始后贴回磁铁能提前停止，OLED 能显示 `BOX HARDWARE TEST` 及 D33/Lid 状态。本轮约定的本地硬件功能测试已获得实物反馈，COM7 已释放，不代表长期稳定或业务链路验收。沿用已确认的 D21、D22、D25、D33 分配。

## 先摆好、断电

1. 拔掉 ESP32 的 USB，接线过程中不通电。本次只使用电脑 USB 供电，不接外部电源。
2. 开发板元件面朝自己，USB 接口朝上，按板上丝印找引脚。用户此前照片中的 3V3 位于左侧最上方，其下为 GND；右侧 VIN 下也有一个 GND。
3. 准备两组电气上互不相连的无源分线接头，各组至少能接一根输入与两根输出。以下临时称为 A、B，这不是接头原有标签，也不代表它们一定是两个独立外壳。
4. A 组只用于 3.3V，B 组只用于 GND。不能将 3V3 与 GND 接进同一组内部互通的分线孔。具体接头外形与孔序尚未由照片确认，不凭孔的位置猜测两组是否独立。

## 第一步：接分线

用户当前照片中的白色双按钮接头，已用 D33 内部上拉与 GND 检查：测试线直接相接时导通；固定左侧一孔，与原右侧孔导通，与另一个右侧孔、另一个左侧孔均未导通（用户报告）。按本次结果，不能把该接头用作本方案的一进二出分线；精确型号和剩余两个孔之间的关系尚未确认。详细过程见[接头通断测试](../硬件/测试/接头通断测试/README.md)。测试只能说明低电流连通，不能代替夹线与线径适配确认。

需准备两组各有至少三个共通夹线位置的一进二出接头：一组分 3.3V，另一组分 GND。每个位置分别可靠夹持一根适配导线，购买前确认支持实际使用的细多股线线径；不能继续采用照片中两根黑线挤入同一个夹线位置的接法。换好接头并确认之前，保持供电分线断开，不接 3V3。

| 一端杜邦母头、另一端剥皮裸铜的转接线 | 电源分线总共需要 6 根，现有够用则不买 | 每个接头接 ESP32、屏幕、蜂鸣器各一根；导体线径需满足端子要求 |

这六根仅用于两组电源分线，不包含门磁的两条转接线。WAGO 官方型号资料将 222-413 标为三个接线位、一个电位，导线截面下限 0.08 mm²；仅作准确规格参考，不代表已经购买或确认用户手中细线的实际线径。参考资料（2026-11-08 核对）：https://www.wago.com/222-413/p/222-413 。购买其他型号时同样确认三个位置全互通及实际线径适配，不能只凭“三孔”商品标题判断。

| 从 ESP32 引出 | 接到哪一组 | 这组接给谁 |
| --- | --- | --- |
| 左上方 3V3 | A 组（3.3V） | 屏幕 VCC、蜂鸣器 VCC |
| 左侧 GND | B 组（地线） | 屏幕 GND、蜂鸣器 GND |
| 右侧 GND | 不需要分线，留给门磁 | 门磁蓝线 |

若某组输出多于两路，多余接口留空并避免裸露金属碰到其他接点。若只有一组互通分线，只能分其中一条电路，不能同时把电源与地线混在这一组。

## 第二步：接屏幕四根线

按屏幕上 VCC、GND、SCL、SDA 的文字识别：

| 屏幕接口 | 接到哪里 |
| --- | --- |
| VCC | A 组任一输出 |
| GND | B 组任一输出 |
| SCL | ESP32 D22 |
| SDA | ESP32 D21 |

屏幕原先能用的 D21、D22 保持不变，只有原来直连 3V3/GND 的两条供电线改从分线组接入。

## 第三步：接蜂鸣器三根线

以板上丝印为准。此前实物照片中，发声圆筒在上、排针朝下、元件面朝自己时，从左到右为 VCC、I/O、GND。

| 蜂鸣器接口 | 接到哪里 |
| --- | --- |
| VCC | A 组另一个输出 |
| I/O | ESP32 D25 |
| GND | B 组另一个输出 |

本次按用户提供的 3.3～5V 工作范围选择 3.3V；VCC 不接 D25。D25 是控制信号，不是供电针脚。

## 第四步：接门磁两根线

| 门磁线 | 接到哪里 |
| --- | --- |
| 棕线 | ESP32 D33 |
| 蓝线 | ESP32 右侧 GND |

两线无源磁簧触点不分正负，棕接 D33、蓝接 GND 是项目统一约定。门磁不用接 3V3 或 VIN。裸线使用可靠接线端子或合适转接线固定，每个接点单独绝缘；若用鳄鱼夹转接，每个夹子只夹各自那根门磁线，两处裸金属不相碰。不把裸线与开发板针脚挤进同一个杜邦插孔。

### 用户选择：保留白色接头转接门磁

2026-11-08 用户明确选择继续使用白色接头，鳄鱼夹转接线仅作备用。门磁棕线与通向 D33 的转接线分别夹在已测通那一对孔的两端；门磁蓝线与通向 GND 的转接线使用余下另一对孔。每孔只夹一根适配导线，夹紧并单独绝缘。余下那对孔未做独立孔间检查，但后续用户报告磁铁靠近、移开时串口读数能够切换，确认本次门磁回路能够响应磁铁。之后用户保持磁铁贴近，`AllHardwareTest` 发送 `c` 校准成功，本次近磁铁关盖电平为 0；不把此值预设为其他安装的通用极性，也不等于已验证长期夹持可靠性。

### 现有鳄鱼夹转接线备用方案

2026-11-08 用户新照片显示已有一端鳄鱼夹、另一端单孔杜邦母头的转接线，可用两根做门磁桌面检测，不必用白色接头转接门磁。此备用方案未单独实测；本轮实际选用白色接头的门磁检测及联动结果见上文与“接完以后”。

先拔 USB，并断开原来的接头测试线与其他模块。任选两根转接线，沿同一根导线确认夹子与母头的对应关系；不按夹子颜色推断用途。

| 转接线 | 鳄鱼夹端 | 同一根线的杜邦母头端 |
| --- | --- | --- |
| 第一根 | 夹住门磁棕线裸铜 | 插 ESP32 D33 |
| 第二根 | 夹住门磁蓝线裸铜 | 插 ESP32 右侧 GND |

夹子要夹稳导体，两处金属夹头分开放置、固定并分别绝缘，不互相接触。该方案仅用于有人看管的桌面检测，不作为药盒内长期安装的接线验收。

此前使用 `ConnectorTest` 的 D33 内部上拉完成门磁原始通断观察，用户已反馈磁铁靠近、移开时读数切换。当前板上已换为 `AllHardwareTest`；串口 115200 发送 `c` 后已把本次磁铁贴近状态记为关盖，电平为 0。重启后须保持磁铁贴近再发送 `c`，不把此次极性硬编码为所有门磁的默认值。

此备用转接方案只处理门磁裸线；每根转接线独立，不代替屏幕、蜂鸣器所需的电源一进二出分线。它未作为本轮实际接法单独验收，不能由白色接头方案的功能结果推断其夹持可靠性。

带线检测端与磁铁分别固定在盒身、盒盖上，使盖子关闭时两者靠近、打开时分离。先移动磁铁确认触发位置，再固定，不能先假定关盖对应 0 或 1。

## 信号针脚定位

开发板方向与前述一致，以实际丝印为准：

- D25：右侧，在 D26 与 D33 之间。
- D33：右侧，在 D25 与 D32 之间。
- D21：左侧，在 D19 与 RX0 之间。
- D22：左侧，在 TX0 与 D23 之间。

## 通电前核对

1. A 组来源只有 3V3，输出只去屏幕 VCC、蜂鸣器 VCC；没有 GND 混入。
2. B 组来源为 GND，输出只去两个模块的 GND；门磁蓝线接另一个 GND。
3. SCL=D22、SDA=D21、蜂鸣器 I/O=D25、门磁棕线=D33，没有相邻错插、松脱或互相接触的裸金属。VIN、EN 等其他针脚保持原状，不用于本次新增接线。

全部核对后才插 USB。若出现明显发热、异味或电脑反复断连，立即断电复核。

## 接完以后

接线正确不等于当前程序已经驱动全部模块。当前已确认上传的是 `AllHardwareTest`；此前 `ConnectorTest` 只检测 D33 通断，不驱动屏幕或蜂鸣器，`BoxOLEDClient` 只读联调程序只驱动 OLED 与联网/计划读取，不操作 D25、D33。

2026-11-08 新增独立的[全部硬件离线测试](../硬件/测试/全部硬件联动/使用说明.md)：已用本机 ESP32 3.3.12-cn、ESP32 Dev Module 编译通过（程序 308580 字节，全局变量 23708 字节），并通过 CLI 成功上传 COM7，写入校验通过并硬复位，识别为 ESP32-D0WD-V3。随后串口 115200 发送 `b`、`s`，收到三声自测及关闭输出回应；用户确认实物“响了三声”。三声自测时 `GPIO33=1`、尚未校准；之后用户保持磁铁贴近，发送 `c` 收到“已把当前状态记为关盖，电平 = 0”，随后 `GPIO33=0 | 关盖 | 蜂鸣器输出=HIGH(关闭)`，本次 RAM 校准成功，重启须重新 `c`。用户进一步确认移开磁铁并保持约 5 秒时自动响三声后停止，观察期间保持打开不反复响；听到响声马上贴回磁铁时能提前停止剩余响铃。用户同时确认 OLED 显示 `BOX HARDWARE TEST` 及 D33/Lid 状态，本轮本地显示、输入与蜂鸣器联动测试均获实物反馈，串口已结束并释放 COM7。该结论仅限本次短时功能观察，不证明接线长期稳定、真实药盒服务或微信通知链路已通过；程序本身不会联网或发送家属通知。新分线接头未到时，仍可断开 OLED 四线，仅直连门磁和蜂鸣器测试。

接线完成后按顺序验证门磁稳定 0/1、确认关盖电平、测试蜂鸣器，再整合到点提醒与真实开盒上传。最终业务仍是“规定时间内未收到有效开盒记录 → 通知已授权家属”，开盖短响只用于接线自测。实测结果需要另行记录，不能把本表当作全功能验收。
