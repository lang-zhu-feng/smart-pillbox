## 硬件结构建议

| 模块 | 图中表现 | 作用及状态 |
| --- | --- | --- |
| ESP32 主控板 | 带屏蔽罩和板载天线区域的紧凑 PCB | 控制提醒、采集开盒事件、通过 Wi-Fi 上传；项目文档已有路线 |
| 开盒检测 | 药格盖边缘的微动开关及小型连接线束 | 检测盖子打开；首版先实现 1 个，完整 21 格布置仅作目标结构概念 |
| 药格提示灯 | 药格边缘的细长 LED 灯板与导光件 | 对应外观图淡青色提示光；布线和驱动为拟设计 |
| 称重组件 | 整盘承重托盘、一个微型应变式梁式称重传感器、HX711 采集小板 | 新增扩展建议：观察整盘重量变化；不定位某格、不识别药物、不宣称精确计数 |
| 声音提醒 | 小型压电蜂鸣器 | 对应现有文档提醒方案；若后续采用真实语音模块，再替换为扬声器和驱动板 |
| 电池与电源 | 扁平单节锂聚合物电池、USB-C 接口、充电/保护/稳压电路 | 拟增加的便携供电方案，容量和型号待定；电池与 PCB 在底部并排安装 |
| 底壳与固定件 | 带螺丝柱、传感器安装座、线槽的注塑底壳 | 支撑实际装配；尺寸和加工方案待验证 |

称重的受力路径：药杯与浮动承重托盘 → 称重传感器受力端 → 传感器固定端 → 底壳。外框与承重托盘保留间隙，避免外框直接承重而绕过传感器。电池和主板固定在下壳，不压在称重托盘上。一个传感器对应整盘重量，不画成可以独立识别 21 格的称重阵列。
